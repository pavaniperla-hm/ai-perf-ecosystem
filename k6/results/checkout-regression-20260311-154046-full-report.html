7 · Root Cause Analysis

Regression Verdict: FAIL — p95 85.68ms vs 30ms threshold (2.9×)

1

Network / Ingress Overhead — Primary Suspect

All 5 transactions fail at similar multiples (2.8–3.3×), with the baseline uniform floor of ~50ms avg. DB query execution is confirmed at 0.08ms via EXPLAIN ANALYZE — the database layer is not the bottleneck. The shared latency floor strongly suggests AKS ingress controller overhead (Nginx ingress), connection keep-alive settings, or the AKS public load balancer round-trip to northeurope. Historical baseline (2026-03-06) showed 42–56ms p95 on 1500ms thresholds — this run's thresholds of 30ms are tighter than the network path can support.

2

txn_order_history — Worst Outlier (175ms p95, 5.8×)

Order history is significantly slower than all other transactions. The ix_orders_user_id index exists and is used by the query planner (Bitmap Index Scan, 0.015ms). However, 53,124 rows and multiple joins or N+1 patterns in the order-service API may explain the additional latency. The order-service Python FastAPI pod consumes 3m CPU and 85MiB — not under pressure — suggesting the latency is I/O-wait or connection-pool wait inside the service, not CPU.

3

Threshold Configuration — Thresholds Set Below AKS Network Floor

The regression-test.js thresholds (p95 < 30ms) are intentionally tight to demonstrate regression detection. The AKS environment incurs ~50ms round-trip latency at p50 — any threshold below this floor will always FAIL on AKS regardless of application changes. This is confirmed by the 2026-03-06 baseline (p95 42–56ms) predating the tight thresholds. Recommend creating separate threshold profiles per environment.

4

Loki Gap — No Log Streams in Test Window

Promtail DaemonSet is running (8m CPU, 81MiB) but returned 0 log streams for {namespace="perf-demo"} during the test window. This is likely a scrape delay (Promtail buffers logs before shipping). No errors were detected — absence of log evidence does not confirm absence of errors. Verify Promtail pipeline config and Loki push URL.
